## 这是什么

按性价比排序的个人发展指南：每条建议写清花掉什么、换回什么、证据有多硬，只引期刊论文、官方文件和被验证过的实战案例。

不用全做：这是一份按性价比排好的备选单，不是任务清单——挑走一两条就算数。

## 跟原书 HowToLiveBetter 的关系

本项目格式参考 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)（CC BY 4.0 + MIT，已授权 fork 衍生）。

**差异化定位**：
- 原书生活向（健康 / 钱 / 法律 / 家庭）→ 本书发展向（学习 / 思维 / AI / 持续性）
- 实战来源：AI 助手规则 / 个人长期记忆 / 决策记录 / 学习提炼

## 12 节目标目录

| # | 节名 | 一句话概述 |
|---|---|---|
| 1 | 不要瞎学 | 选什么的成本-收益，避免无的放矢 |
| 2 | 不要瞎忙 | 时间精力分配，防打断 / 防切换 |
| 3 | 不要瞎读书 | 阅读的成本-收益，先看结构再读 |
| 4 | 不要瞎思考 | 思维框架，第一性原理 / MECE |
| 5 | 不要瞎决策 | 决策系统，决策记录格式 |
| 6 | 不要瞎记录 | 知识管理，markdown + 个人笔记系统 |
| 7 | 不要瞎努力 | 习惯 vs 决心，微习惯 |
| 8 | 不要瞎防御 | 思维陷阱，沉没成本等 |
| 9 | 不要瞎求助 | 人际网络，提问边界 |
| 10 | 不要瞎 AI | 个人 AI 助手搭建 |
| 11 | 不要瞎健康 | 身体 vs 发展，久坐 / 睡眠 |
| 12 | 不要瞎持续 | 长期持续性本身，反烂尾 |

每节目标 15-30 条，按性价比排序。

## 怎么贡献

1. **Issue 提需求**：挑错 / 加新条目建议 / 反例
2. **PR 直接改内容**：修改 `book/0X-*.md`（当章节拆分后）
3. **AI skill 建议**：先开 Issue 讨论再写代码

### 条目格式模板

每条按以下结构写：

```markdown
### N. 动词开头的一句话标题
<!-- 成本标签: 钱=0/少/多 时间=少/中/多 毅力=否/些/是 收益=大/中/小 口径=死亡率/金钱/时间/自由 -->
- 成本：...
- 说人话：...
- 收益：...
- 证据等级：A / B / C
- 来源：作者 (年份). 标题. 期刊/出版社.
- 备注：争议 / 适用人群 / 例外
```
