# 第 6 节 · 不要瞎记录

> 知识管理，markdown + 个人笔记系统

#### 1. 每天写 1 行日记，不追求"完整笔记"
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=大 口径=时间 -->
- **成本**：1-5 分钟 / 天
- **说人话**：知识管理最大杀手是"等有时间再好好写"。每天 1 行（日期 + 一句要点）比周末写 5 小时有用 10 倍。daily note 模式就是这个实践
- **收益**：10x 留存率；30 天后能回看"那时想什么"
- **证据等级**：B
- **来源**：Ahrens (2017). *How to Take Smart Notes*. 第一章"为什么卡片盒能让你写出书".
- **备注**：日记 ≠ 完整记录。追求"完整"是借口，最终都放弃

#### 2. Zettelkasten — 卡片盒笔记法
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：学 1 套方法 + 持续
- **说人话**：一张卡片 = 一个原子化想法 + 链接到其他卡片。**好处是 100 张卡片能写一本书**——卡片之间自然连成体系
- **收益**：知识复用率提升 10 倍
- **证据等级**：B
- **来源**：Ahrens (2017). *How to Take Smart Notes*. 全书
- **备注**：Niklas Luhmann 用此法写 70+ 本书

#### 3. 用 markdown > 用 word
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 口径=时间 -->
- **成本**：学 markdown（30 分钟）
- **说人话**：markdown 可版本控制、可搜索、可跨设备、可自动化。word / Pages 锁死在 .docx
- **收益**：长期可持续性 10 倍
- **证据等级**：B
- **来源**：Markdown + Git 实践共识
- **备注**：Obsidian / VS Code / Vim / Emacs / Logseq 都用 markdown

#### 4. 不要追求"完整笔记"
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=中 口径=时间 -->
- **成本**：自律
- **说人话**：记 100 行重点 > 写 10 小时完整。**完整 = 借口，3 行就够**
- **收益**：记录速度提升 5 倍；留存率提升
- **证据等级**：B
- **来源**：PKM 经验
- **备注**：详见第 1 节 — 学完用在哪

#### 5. 标签不要超过 7 个
<!-- 成本标签: 钱=0 时间=少 毅力=中 收益=中 口径=时间 -->
- **成本**：自律 标签收敛
- **说人话**：标签多了 = 找不到。短期记忆 7±2 个项目——**超过 7 个标签 = 实际不用**
- **收益**：查找时间减少 80%
- **证据等级**：B
- **来源**：Miller (1956). "The magical number seven". *Psychological Review*.
- **备注**：层级分类 > 多标签

#### 6. 每个笔记有"用途"
<!-- 成本标签: 钱=0 时间=少 毅力=中 收益=中 口径=时间 -->
- **成本**：每笔记一行
- **说人话**：开头写"用于 X"——意图清晰 = 复用率高。没用途的笔记 = 不会看
- **收益**：30 天后复用率提升 50%
- **证据等级**：B
- **来源**：Zettelkasten 方法 / PKM 经验
- **备注**：类似编程里的"接口"概念——意图 > 实现

#### 7. 每周做一次"复盘笔记"
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：每周 30-60 分钟
- **说人话**：本周做了什么 / 为什么 / 什么有效 / 什么无效。**复盘 = 学习的杠杆**——同样的经验，复盘过的人学得快 3 倍
- **收益**：学习速度提升 3 倍
- **证据等级**：B
- **来源**：Argyris (1977). *Double Loop Learning*. + 反思实践研究
- **备注**：单循环学习 = 同样错误；双循环 = 改方法

#### 8. 同类笔记 ≠ 同一笔记
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：自律 整合
- **说人话**：同一想法散在多个地方 = 找不回。**集中到一处，引用时链接**
- **收益**：查找 + 复用率提升
- **证据等级**：B
- **来源**：PKM 经验
- **备注**：Obsidian 双链 = 解决这个

#### 9. 笔记要"原子化"——一张一意
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：自律 拆分
- **说人话**：1 笔记 1 主题。**1 笔记混多主题 = 引用困难 = 0 复用**
- **收益**：复用率 + 100%
- **证据等级**：B
- **来源**：Zettelkasten 核心理念
- **备注**：最小可复用单元 = 原子化笔记

#### 10. 用双链 — 别只用文件夹
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：学 Obsidian 双链
- **说人话**：文件夹 = 树状结构（一维）；**双链 = 网状结构（多维）**。人的思维是网状的
- **收益**：查找 + 复用率 + 50%
- **证据等级**：B
- **来源**：Obsidian / Roam Research 实践
- **备注**：双链让笔记"自动产生连接"

#### 11. 不收集 = 不读
<!-- 成本标签: 钱=0 时间=少 毅力=是 收益=大 口径=时间 -->
- **成本**：自律 + 删除
- **说人话**：收藏 1000 篇 = 读了 0 篇。**不读 = 删**
- **收益**：信号噪声比 + 100%
- **证据等级**：B
- **来源**：信息管理实践
- **备注**：收藏 ≠ 知识

#### 12. 每月清空一次
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=中 口径=时间 -->
- **成本**：1-2 小时 / 月
- **说人话**：30 天前的临时笔记 / 截图 / 链接 = 多数无用。**清掉 = 内存整理**
- **收益**：长期系统健康
- **证据等级**：B
- **来源**：PKM 经验
- **备注**：类似"数字断舍离"
