# 第 10 节 · 不要瞎 AI

> 个人 AI 助手搭建

#### 1. 把"我反复说过的话"写成 SKILL.md，别每次重 prompt
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：写 1 个 SKILL.md（首次 2-4 小时）
- **说人话**：AI 助手最贵的成本是"每次都重新解释你的偏好 / 流程"。把反复用的写成 skill，**description 写清楚触发词**，AI 自动加载。个人 AI 助手用户通常会自建几十到上百个 skill 处理重复偏好。最近一个例子：用 life-decision-guide skill 自动匹配《高性价比人生指南》第 8 节法律条目
- **收益**：效率 + 一致性；个人偏好数字化 = 团队 / 家人可继承
- **证据等级**：B
- **来源**：Anthropic (2026). *Building Effective Skills*. + GitHub multica-ai/andrej-karpathy-skills.
- **备注**：**国内蓝海**。英文向有 karpathy-guidelines（编码向），生活向有 HowToLiveBetter 的 life-decision-guide skill；**中文 + 个人发展 + 实战** 是空白

#### 2. 写好 description — skill 的"触发词"
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：写 30 分钟
- **说人话**：description 是 skill 唯一被"看到"的地方。**写不清触发词 = 触发不了**
- **收益**：技能命中率提升 5 倍
- **证据等级**：B
- **来源**：Anthropic Skills Building Guide (2026)
- **备注**：触发词要带用户的口语说法

#### 3. 读 SKILL.md 嵌入原文 — 不是只读 description
<!-- 成本标签: 钱=0 时间=少 毅力=中 收益=大 口径=时间 -->
- **成本**：自律
- **说人话**：SKILL.md 是"操作手册"——触发后必须读。**只读 description = 0% 用法**
- **收益**：使用率提升 80%
- **证据等级**：A
- **来源**：Anthropic 2026
- **备注**：触发 = 加载 description；触发后必须读 SKILL

#### 4. 区分 SKILL vs MCP
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=中 口径=时间 -->
- **成本**：理解概念
- **说人话**：SKILL = "什么时候、怎么用"；MCP = "我能调什么工具"。**MCP 是工具，SKILL 是说明书**
- **收益**：架构清晰
- **证据等级**：B
- **来源**：Anthropic 2026 + Model Context Protocol 规范
- **备注**：SKILL 没 MCP 也能用，只是没外部工具

#### 5. 先讲 context — AI 没上下文
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：写 1-2 段
- **说人话**：AI 给完就忘。**每次开始新对话要重新讲背景**
- **收益**：避免"AI 给错"的 80% 情况
- **证据等级**：A
- **来源**：LLM 基础
- **备注**：每日笔记 / 配置文件 / 长期记忆 都为此服务

#### 6. AI 输出要"实测" — 数字 / 引用 / 人物
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：搜索 5-10 分钟
- **说人话**：AI 凭印象补数字 / DOI / 法条 = 错的概率 5-30%。**关键数据必须实测**
- **收益**：避免错误决策
- **证据等级**：A
- **来源**：LLM 实证评测（多篇）
- **备注**：LRN（learn-not-repeat）— AI 错过一次就要长期记忆

#### 7. AI 工具 > AI 替代 — 1 人做 10 人事
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=中 口径=时间 -->
- **成本**：理解
- **说人话**：AI 不是"替掉人"——**让 1 人做 10 人的事**。需要的是"会用 AI"不是"被 AI 替"
- **收益**：长期职业生涯
- **证据等级**：B
- **来源**：AI 应用研究综合
- **备注**：不适用于"AI 直接面向用户"的场景

#### 8. 保持 AI 输出可追溯 — 哪里来 / 出自哪个版本
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：记录
- **说人话**：AI 输出留了哪"什么"指 — 一个月后你能重做这个输出。**不可追溯 = 编辑降级**
- **收益**：长期生产力
- **证据等级**：B
- **来源**：SKILL / WAL Protocol / 工程实践
- **备注**：配置文件 / WAL 都是这个

#### 9. 先写本地 1 个 skill 再扩 — 别上来就写 10 个
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：1 个 skill 写 2-4 小时
- **说人话**：先解决你最痛的一个问题 = 验证 skill 价值。**然后 1 周 1 个** = 自然扩张
- **收益**：避免"为写而写"
- **证据等级**：B
- **来源**：Anthropic 2026 / SKILL 作者经验
- **备注**：跟第 7 节 — 微习惯同源

#### 10. SKILL 文件路径要在 description 写清
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：写 description 时多想 30 分钟
- **说人话**：description 是 LLM 唯一"扫到"的——**说清"何时用、用什么文件路径、触发词"**
- **收益**：命中率 + 50%
- **证据等级**：B
- **来源**：Anthropic SKILL 编写指南
- **备注**：LLM 看不到文件名

#### 11. 写"反面示例"——不做什么
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：写 30 分钟
- **说人话**：SKILL 不仅说"做什么"，也要说"不做什么"。**负向触发 = 避免误用**
- **收益**：误用率 - 70%
- **证据等级**：B
- **来源**：SKILL 编写实践
- **备注**：见第 4 节 — 决策边界

#### 12. SKILL 用"步骤列表"——别用段落
<!-- 成本标签: 钱=0 时间=少 毅力=中 收益=大 口径=时间 -->
- **成本**：自律
- **说人话**：LLM 跟随"有序步骤"比"段落"准确 50%。**1. 2. 3. > 一段话**
- **收益**：执行准确度 + 50%
- **证据等级**：A
- **来源**：LLM 提示工程研究
- **备注**：结构化输出 = LLM 友好

#### 13. 测试 skill 至少 10 个不同问题
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：30 分钟测试
- **说人话**：1 个问题测过 ≠ skill 工作。**至少 10 个问题 = 才知道边界**
- **收益**：可靠性 + 50%
- **证据等级**：B
- **来源**：SKILL 作者最佳实践
- **备注**：含"应该触发"和"不应该触发"

#### 14. SKILL 要"幂等"——多次触发 = 同样结果
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：自律 设计
- **说人话**：同一问题触发 N 次 = N 次同样答案。**幂等 = 可依赖**
- **收益**：可靠性 + 100%
- **证据等级**：A
- **来源**：工程学原则
- **备注**：避免"看心情"答案

#### 15. AI 输出"必须复查"——特别是数据
<!-- 成本标签: 钱=0 时间=中 毅力=中 收益=大 口径=时间 -->
- **成本**：每条输出 5 分钟验证
- **说人话**：LLM 输出数字 / 引用 / 名字 = 经常错。**关键决策前必须实测**
- **收益**：决策错误率 - 70%
- **证据等级**：A
- **来源**：LLM 实证评测
- **备注**：见第 10 节条目 6

#### 16. 不要让 AI 替你做情绪决策

- **成本**：自律
- **说人话**：感情 / 人生方向 = AI 不懂你。**AI 适合结构化决策，不适合价值决策**
- **收益**：决策真实性
- **证据等级**：B

#### 17. AI 帮"先草稿"——别让它"最后定稿"
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 口径=时间 -->
- **成本**：自律
- **说人话**：AI 写 80%，你改 20% = 高效；**AI 写 100% = 你 0% 学习**
- **收益**：效率 + 学习
- **证据等级**：B
- **来源**：AI 应用实践
- **备注**：同第 1 节 — 学完要用

- **收益**：决策更安全
- **证据等级**：B
- **来源**：实践共识
